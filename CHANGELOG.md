# Changelog

All notable changes to EN-identity are documented here.

## 1.0.0

- Custom dark-red registration NUI.
- ENZO CODE branding and startup console banner.
- Resource-name validation for `EN-identity`.
- First name, last name, date of birth, height and gender registration.
- ESX identity data integration.
- Multichar compatibility retained.
- Test UI command: `/testidentity`.
- GitHub-ready project structure and documentation.
